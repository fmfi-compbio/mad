NAME

CPAN::Version - utility functions to compare CPAN versions

SYNOPSIS

  1.   use CPAN::Version;
  3.   CPAN::Version->vgt("1.1","1.1.1");    # 1 bc. 1.1 > 1.001001
  5.   CPAN::Version->vlt("1.1","1.1");      # 0 bc. 1.1 not < 1.1
  7.   CPAN::Version->vcmp("1.1","1.1.1");   # 1 bc. first is larger
  9.   CPAN::Version->vcmp("1.1.1","1.1");   # -1 bc. first is smaller
  11.   CPAN::Version->readable(v1.2.3);      # "v1.2.3"
  13.   CPAN::Version->vstring("v1.2.3");     # v1.2.3
  15.   CPAN::Version->float2vv(1.002003);    # "v1.2.3"

DESCRIPTION

This module mediates between some version that perl sees in a package and the version that is published by the CPAN indexer.

It's only written as a helper module for both CPAN.pm and CPANPLUS.pm.

As it stands it predates version.pm but has the same goal: make version strings visible and comparable.
