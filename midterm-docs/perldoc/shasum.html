NAME

shasum - Print or Check SHA Checksums

SYNOPSIS

  1.  Usage: shasum [OPTION]... [FILE]...
  2.  Print or check SHA checksums.
  3.  With no FILE, or when FILE is -, read standard input.
  5.    -a, --algorithm   1 (default), 224, 256, 384, 512, 512224, 512256
  6.    -b, --binary      read in binary mode
  7.    -c, --check       read SHA sums from the FILEs and check them
  8.        --tag         create a BSD-style checksum
  9.    -t, --text        read in text mode (default)
  10.    -U, --UNIVERSAL   read in Universal Newlines mode
  11.                          produces same digest on Windows/Unix/Mac
  12.    -0, --01          read in BITS mode
  13.                          ASCII '0' interpreted as 0-bit,
  14.                          ASCII '1' interpreted as 1-bit,
  15.                          all other characters ignored
  17.  The following five options are useful only when verifying checksums:
  18.        --ignore-missing  don't fail or report status for missing files
  19.    -q, --quiet           don't print OK for each successfully verified file
  20.       -s, --status          don't output anything, status code shows success
  21.        --strict          exit non-zero for improperly formatted checksum lines
  22.    -w, --warn            warn about improperly formatted checksum lines
  24.    -h, --help        display this help and exit
  25.    -v, --version     output version information and exit
  27.  When verifying SHA-512/224 or SHA-512/256 checksums, indicate the
  28.  algorithm explicitly using the -a option, e.g.
  30.    shasum -a 512224 -c checksumfile
  32.  The sums are computed as described in FIPS PUB 180-4.  When checking,
  33.  the input should be a former output of this program.  The default
  34.  mode is to print a line with checksum, a character indicating type
  35.  (`*' for binary, ` ' for text, `U' for UNIVERSAL, `^' for BITS),
  36.   and name for each FILE.  The line starts with a `\' character if the
  37.   FILE name contains either newlines or backslashes, which are then
  38.   replaced by the two-character sequences `\n' and `\\' respectively.
  40.   Report shasum bugs to mshelor@cpan.org

DESCRIPTION

Running shasum is often the quickest way to compute SHA message digests. The user simply feeds data to the script through files or standard input, and then collects the results from standard output.

The following command shows how to compute digests for typical inputs such as the NIST test vector "abc":

  1. 	perl -e "print qq(abc)" | shasum

Or, if you want to use SHA-256 instead of the default SHA-1, simply say:

  1. 	perl -e "print qq(abc)" | shasum -a 256

Since shasum mimics the behavior of the combined GNU sha1sum, sha224sum, sha256sum, sha384sum, and sha512sum programs, you can install this script as a convenient drop-in replacement.

Unlike the GNU programs, shasum encompasses the full SHA standard by allowing partial-byte inputs. This is accomplished through the BITS option (-0). The following example computes the SHA-224 digest of the 7-bit message 0001100:

  1. 	perl -e "print qq(0001100)" | shasum -0 -a 224
