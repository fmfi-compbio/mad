NAME

ptardiff - program that diffs an extracted archive against an unextracted one

DESCRIPTION

  1.     ptardiff is a small program that diffs an extracted archive
  2.     against an unextracted one, using the perl module Archive::Tar.
  4.     This effectively lets you view changes made to an archives contents.
  6.     Provide the progam with an ARCHIVE_FILE and it will look up all
  7.     the files with in the archive, scan the current working directory
  8.     for a file with the name and diff it against the contents of the
  9.     archive.

SYNOPSIS

  1.     ptardiff ARCHIVE_FILE
  2.     ptardiff -h
  4.     $ tar -xzf Acme-Buffy-1.3.tar.gz
  5.     $ vi Acme-Buffy-1.3/README
  6.     [...]
  7.     $ ptardiff Acme-Buffy-1.3.tar.gz > README.patch

OPTIONS

  1.     h   Prints this help message

SEE ALSO

tar(1), Archive::Tar.
